# 构件识别与拆分（CAD 图通用）

适用于任何 CAD 图：建筑、结构、装修、测绘、开发商户型图。每个构件在图面上长什么样、和谁容易混，先查 [构件图鉴](component-catalog.md)。目标不是"给每条线贴个名字"，而是把图元拆成**可用的构件实例**：一段墙、一根梁、一樘窗、一个柱、一个洞口。

## 0. 输出两层

| 层 | 粒度 | 用途 |
|---|---|---|
| `assignments` | 每个图元属于哪个构件类别 | 逐条核对、找出漏判 |
| `instances` | 一个构件（由若干图元构成） | 算长度/厚度/面积、挂门窗洞口、进模型 |

只做第一层等于没拆：一条线一个标签，图上是什么样数据里还是什么样。

## 1. 判断顺序（固定）

1. **图例 / 门窗表 / 材料表** —— 有就以它为准，覆盖下面所有规则
2. **图层名** —— `A-WALL-建筑墙体`、`Y-梁`、`■18■ 门`、`P-固定家具` 这类直接说明类别
3. **几何形态** —— 双线带、实心填充、开启弧、平行细线、踏步阵列
4. **相邻与包被关系** —— 在墙里的线是洞口收边，不在任何墙里的孤立线要单独判
5. **颜色** —— 只作候选，不作结论：同一颜色可能对应多个类别，ByLayer/打印样式/单色出图会抹掉它
6. **文字与标注** —— `C1`、`M1`、`KL-1`、`1200×2100` 能定编号与尺寸，但先确认它引的是哪个构件

任何一步得出多个可能，就保留待核，别二选一硬猜。

## 2. 逐类：怎么认、怎么拆

### 墙

| 画法 | 认法 | 拆法 |
|---|---|---|
| 双线带（最常见） | 两条平行线，间距 = 墙厚；投影重叠 ≥ 60% | 一条带 = 一段墙；厚度取间距 |
| 单线中线 | 一条线，两侧有对称的垛口/门洞 | 一条线 = 一段墙，厚度查标注或同图其他墙 |
| 实心 / 斜线 / 网格填充 | 闭合或半闭合轮廓内部填充 | 填充轮廓 = 一段墙（或柱，见下） |

**断开点**（这几处必须切成不同实例）：

- 与另一方向墙的交点
- 厚度变化处（200 → 100）
- 材质变化处（砌体 / 混凝土 / 轻质）
- 洞口两侧：洞口把墙断开，洞口自成实例并挂在这段墙上

**不要**：跨过洞口把两段连成一条；把墙垛并进长墙；把家具轮廓（矩形 + 分隔线）当墙。

### 柱 / 墙垛

- 柱：封闭轮廓（矩形、L 形、圆形），常带实心填充；长宽比接近，四边都有墙或独立
- 墙垛：贴墙的短段，一边与墙齐平；本质是墙的加厚段
- 管道井 / 风道：小房间围合，内部常有交叉线或填充，四面是墙
- 判据：**尺寸 + 邻接**。单看闭合轮廓分不清柱和家具，看图例或看它是否在墙线上

### 梁

- 认：梁图层、梁位标注（`KL1(2) 200×500`）、双虚线、常与墙同色
- 拆：一条梁可能画成多段（虚线、被柱子打断），按共线 + 间隙合并成一根；交叉处断开
- 梁**通常不闭合**，是一根线；不要为了"闭合"把它围成矩形
- 梁下有墙还是无墙（过梁/圈梁/主梁）要看结构图，图上分不出就别写

### 门

- 认：门扇线（一段短直线或细长矩形）+ 开启弧（90° / 60° / 45°）
- 解析：弧心 = 门轴，弧的两个端点 = 关闭位与开启位；弧在哪侧就往哪侧开
- 变体：双开（两段弧，半径相等）、子母门（半径不等）、推拉门（两段错位扇框，无弧）、折叠门（多段折线扇）、转门（多扇 + 圆心）
- 拆：**门洞（洞口）与门扇分开**。洞口属于墙，门扇挂在洞口上；组合门窗拆成「门扇 + 固定段 + 边框」

### 窗

- 认：洞口内 3–4 根平行细线 + 端部收边；常青（ACI 4），但颜色不可靠
- 变体：推拉窗（两段错位、各占一半）、飘窗（凸出外墙一圈平行线）、幕墙（分格网 + 竖梃）
- 拆：一樘窗一个实例，宽度取洞口净宽；窗台高、窗高以标注为准，没有就留待核

### 洞口

- 认：墙带上的断口，两侧有收边线，断口里没有门扇也没有窗线（或者有边框贯穿扇与固定段）
- 拆：洞口 = 一个实例，必须挂到某段墙；宽度取净宽
- 与门洞的区别：有门扇/开启弧的是门洞，纯断口是洞口

### 楼梯 / 电梯 / 扶梯

- 楼梯：踏步阵列（等距平行线）+ 上下行箭头 + 剖断线；一段梯段一个实例
- 电梯：井道轮廓 + 轿厢 + 对重 + 导轨；井道与轿厢分开
- 扶梯：斜向踏步带 + 扶手线

### 固定构件

- 固定柜：柜体轮廓 + 内部分隔线 + 落地到顶/不到的差别看说明
- 台面 / 岛台：台面轮廓，常与柜体共边
- 洁具：马桶、洗手盆、浴缸的封闭轮廓，常带图块名
- 设备：空调外机、热水器、洗衣机——矩形 + 型号文字，没有文字就只标待核

### 表达层（不是构件）

轴线、轴网、尺寸、文字标注、标高、填充、图框、会签栏、修改云线、指北针、图例。这些归 `annotation` / `axis` / `dimension` / `hatch` / `title` / `revision` / `north`，不参与面积与构件统计。

## 3. 拆分粒度

| 构件 | 一个实例 = |
|---|---|
| 墙 | 两个断开点之间的一段（洞口两侧各算一段） |
| 梁 | 一根连续梁（虚线合并后），交叉处断开 |
| 柱 | 一个闭合轮廓 |
| 门 / 窗 | 一樘（组合门窗按扇拆） |
| 洞口 | 一个净洞 |
| 楼梯 | 一段梯段（上行 / 下行分开） |

原则：**能被单独计量、单独修改的最小单元**。建模时要动它、出图时要标它，就是一个实例。

## 4. 拆完自检

- 每个图元都有归属，或者明确归到 `other` 并写明原因
- 一个图元不能被两个实例同时占用
- 洞口都有宿主墙；门窗都有宽度；墙都有厚度
- 实例总长 / 总面积与图上的总尺寸、房间面积标注对得上（差 5% 以上要查）
- 不做无依据的闭合：梁、墙中线、窗带本来就不是环
- 承重 / 非承重没有结构图或图例就不写，写「待核」

## 5. 输出格式

```json
{
  "kinds": {
    "wall":  {"label": "墙体", "color": "#65409a", "geometry": "open", "group": "structural"},
    "pier":  {"label": "柱／墙垛", "color": "#793131", "geometry": "ring", "group": "structural"},
    "window":{"label": "窗", "color": "#007891", "geometry": "span", "group": "structural"}
  },
  "assignments": {
    "1817": {"kind": "wall", "provenance": "ai", "confidence": 0.7, "basis": "与 1818 平行，间距 200mm"},
    "2C2":  {"kind": "wall", "provenance": "ai", "basis": "同上，带内边线"}
  },
  "instances": {
    "W-001": {"kind": "wall", "geometry": "band", "members": ["1817", "2C2"],
              "length": 4200, "thickness": 200, "openings": ["O-003"],
              "basis": "两条平行线间距 200mm、投影重叠 92%", "provenance": "ai", "confidence": 0.7},
    "O-003": {"kind": "window", "geometry": "span", "members": ["2C7"], "host": "W-001",
              "width": 1500, "basis": "洞口内 3 根平行线", "provenance": "ai", "confidence": 0.8},
    "P-011": {"kind": "pier", "geometry": "ring", "members": ["2C2", "2C3"],
              "area": 0.16, "basis": "封闭轮廓 + 实心填充", "provenance": "ai", "confidence": 0.9}
  }
}
```

`basis` 写「凭什么这么判」，`confidence` 写真实把握；两者缺一，下一个人就无法复核。

## 6. 典型失败模式

| 失败 | 现象 | 正确做法 |
|---|---|---|
| 把图库块当平面 | 一张户型图出现 900 多个「家具」图元 | 大块只记引用（`library: true`）；`space cad inspect` 默认这样处理 |
| 一条线一个标签就算拆完 | 数据里 185 条「墙」，仍然不知道有几段墙、多厚 | 先配对成带，再切段，产出 `instances` |
| 虚线段当成一根梁 | 「梁 27 根」总长只有 3 米 | 共线合并虚线段，得到真实梁长 |
| 用颜色定类型 | 黄线一律当门，结果标注文字也被当门 | 颜色只作候选，图层名与几何优先 |
| 强行闭合 | 给梁、墙中线硬套矩形 | 按构件决定要不要环；`geometry` 写清 |
| 跨洞口连墙 | 一段墙穿过门洞，面积算大 | 洞口断开墙段，洞口单独成实例 |
