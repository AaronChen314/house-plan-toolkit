# 构件图鉴：图面上怎么认出每个构件

读图时按这份图鉴找证据：先说这是什么构件，再说它怎么画、容易和谁混。
**这不是白名单**：项目只在 `data/cad/components.json` 里声明自己用到的类别；图鉴负责"怎么认"。

## 怎么用

1. 先按图例/图层名/文字确定体系（结构 / 围护 / 门窗 / 设备 / 装修 / 室外 / 标注）
2. 再看画法对号入座；同一构件常有多种画法，图鉴里列了主要变体
3. 认不准就保留待核，写清"像 X，但缺 Y 证据"，不要二选一硬猜

`geometry` 只是几何用法提示：`ring` 闭合轮廓、`open` 线状、`span` 跨度（两端落在别的构件上）、`area` 面域填充。

## 认不出来时的处理

- 写「像 X，缺 Y 证据」，confidence 给低值，不要硬归类
- 一类构件在不同院差别很大（尤其吊顶、幕墙、定制柜），**以图例和文字为准**
- 同一条线可能同时是「墙的边线」和「洞口的收边」：按它在哪一端、和谁相连判断，不要重复归类
- 图例、门窗表、材料表出现时，先抄它们，再对图
