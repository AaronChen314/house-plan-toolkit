# 空间工作流共享约定

供“CAD 转数据 → 户型设计 → 三维白模”三个领域流程，以及“设计版本到三维同步”和“设计图像出图”两个交付入口共同使用。它规定信息含义和衔接方式，不声明仓库已有统一 BIM 格式，也不要求改写现有数据结构。

## 维护方式

- 优先沿用当前项目可用的数据格式。用已有字段或独立的元数据文件补充下述信息，记录字段映射；不要把工具不认识的字段直接塞进严格 Schema。
- cad-structure/v2（structure-format.md） 是可追溯二维线框格式，并不天然包含宿主墙、空间拓扑或楼层标高。[HouseSpec](spec-format.md) 是设计器输入。两者不等价，转换时记录新增、推断和无法映射的内容。
- 公共白模采用 [space-model/v1](README.md)，源图索引为 `cad-source/v1`；具体支持范围以该接口为准。共享约定里的关系并不都已被渲染器实现。
- 原始资料、设计变更、三维表现分别保存。构件用稳定 ID；重新生成或更换模型资源不随意改变 ID。拆分、合并记录前后对应关系。
 - 设计更新已有三维时，用 design-sync/v1（design-sync-manifest.md） 记录版本、变更类别、批准依据、固定机位和门禁结果。预览图只作验收视图，不能代替设计数据。
 - 基础图与风格图生成彩平或效果图时，按 出图模板（design-image-prompts.md） 固定参考图角色。几何、开口、家具数量和镜头由基础图锁定；风格图只提供材质、配色、灯光和软装。生成图是表现层派生结果，不能反向覆盖空间数据。

## 最少要能表达的信息

| 信息 | 内容 |
|---|---|
| 资料身份 | 文件、版本、用途（原始/设计/实测等）、有效状态，必要时保留指纹 |
| 坐标 | 单位、坐标轴方向、每层原点、到建筑统一坐标的变换及依据 |
| 楼层与局部空间 | 完成面标高、层高、净高、板及地面构造；局部降板、吊顶、梁底、夹层、挑空 |
| 构件 | 稳定 ID、类型、所属楼层/空间、平面几何、竖向范围及尺寸依据 |
| 关系 | 门窗宿主墙、门连通的空间、上下层对应构件、楼梯连接楼面、柜体上方顶面、管路与设备连接 |
| 来源 | 原图句柄或块实例路径；图片/PDF页码与区域；用户确认或推断的文字依据 |
| 问题 | 冲突对象、证据、影响范围、当前处理及待确认项 |
| 修改 | 基准版本、对象 ID、修改前后值、原因；设计变更与用户覆盖值分开记录 |

关系尚未核实时可以为空，并记录未知原因，不能因字段存在就默认关系成立。一个 CAD 图块可对应多个构件，一个构件也可来自多个图元。

## 数值依据

按参数记录，而非给整个对象统一盖章：`drawing`（图纸明确）、`measured`（实测）、`user_confirmed`（用户明确）、`derived`（有依据计算）、`inferred`（推断）、`preview`（仅预览）、`unknown`（未知）。可映射到现有项目的等义枚举。

- 推导值保留公式及输入来源。未知用空值，不能用0代替；真实的0窗台、0标高必须有依据。
- 图纸平面占地准确，不代表其高度已知。识别出的柜型与具体柜高也分别记录。
- 同一字段出现冲突时保留各方依据与当前采用值，不通过静默缩放、平移或覆盖消除矛盾。
- 预览参数集中保存，不写回原始事实；最终界面和交付说明中能识别这些参数。

## 空间关系的核查

- 在同一基准下，下一层完成面标高 = 当前完成面标高 + 两完成面之间的层高。
- 局部净高由该处完成面与有效顶面决定；梁、吊顶、板底、面层可能不同。不能无条件用“层高减板厚”代替净高。
- 多层对齐用轴网、柱、墙等独立锚点复核，保留误差。二维图纸画在一起或同名井道，不等于竖向自然对齐。
- 夹层、楼梯、挑空分别关联相应楼面和洞口；到顶柜关联所在位置的有效顶面，不简单读取整层最大高度。
- 平面通道检查包含门扇、柜门、家具使用空间；竖向检查包含楼梯/门洞净空、柜顶、窗台与台面、设备检修空间。
- 管路记录系统、连接点及必要的高度/坡向等约束；缺少管径、排水接入标高或设备资料时，表达为待核路线，不能宣称可施工。
- 更改标高、板厚、墙位、洞口、柜型或设备位置后，只重算依赖它的关系，并检查新增冲突。

## 用户修改与交付

- 重建前识别用户修改发生在数据、生成器、HTML、资源文件还是浏览器存储；对涉及文件备份，记录当前入口。若无法读取浏览器修改，应明确保留状态尚未验证。
- 能重现当前结果后再增量修改；无法重现时保留现有成品，先找出差异，不直接用旧生成器覆盖。
- 显式覆盖值优先于自动推断。新需求与旧覆盖冲突时记录冲突；没有冲突的用户选择继续保留。
- 交付说明包含入口、数据/源码位置、主要变更、已核查项目与未核查项。预览通过不等于结构、机电或施工审查通过。
